# Employee_Management_System
### Instructions

1. **Running the Program**
   1. **Executing Bytecode**
      1. Navigate to `20210353_KimHyunjin_JavaAssignment5/bin` in the command prompt.
      2. Execute the program using the command: `java employeeTest/EmployeeManagementSystemGUI`
   2. **Executing JAR File**
      1. Navigate to `20210353_KimHyunjin_JavaAssignment5` in the command prompt.
      2. Run the JAR file using the command: `java -jar 20210353_KimHyunjin_JavaFinalAssignment_JARFile.jar`

2. **Program Features**
   1. **Functionality**
      1. **Register Employee Information**: Supports both permanent and temporary employees.
      2. **Search Registered Employee Information**: 
         - Search all employees
         - Search permanent employees
         - Search temporary employees
         - Search by name
      3. **Update Employee Information**: Update registered employee information using the employee ID.
      4. **Delete Employee Information**: Delete registered employee information using the employee ID.
      5. **Save Employee Information**: Save employee information in a text file in CSV format, instead of storing it within the program.
      6. **Load Employee Information**: Load employee information from a text file into an array within the program.
   2. **File Input/Output**
      1. Employee information can be inputted and outputted through the `employees.txt` file.
      2. When saving employee information, the program copies the employee information from the array into the text file.
      3. When loading employee information, the program retrieves the stored employee information from the text file and loads it into the array within the program.
